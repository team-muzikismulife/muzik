# 공동 공유 플레이리스트 계획

## 배경

팀 홈은 오늘의 팀원별 추천곡과 날짜별 상세로 이동할 수 있지만, 방 전체에 쌓인 곡을 한 번에 모아 재생하는 화면이 없다.
사용자가 기대하는 경험은 유튜브 재생목록처럼 팀 곡을 이어 듣고, 유튜브에서 열린 임시 재생목록을 저장하는 흐름이다.

## 목표

1. 방 홈에서 공동 플리 화면으로 이동할 수 있는 진입점을 만든다.
2. `rooms/{roomId}/tracks` 전체를 등록 순서대로 읽어 공동 큐를 구성한다.
3. 유튜브 핸드오프(`watch_videos`)와 인앱 미리듣기를 제공한다.
4. loading / empty / error / ready 네 상태를 모두 처리한다.

## 범위

- 이번 이슈는 읽기 중심의 공동 큐 화면을 만든다.
- 곡 등록 Cloud Function과 등록 모달은 기존 미구현 상태를 유지하고, 버튼은 준비 중 토스트로 연결한다.
- 실제 YouTube 계정에 `playlists.insert`로 재생목록을 생성하지 않는다. `docs/유튜브연동설계.md`의 결정대로 유튜브 핸드오프 후 저장 버튼을 쓰는 흐름을 따른다.

## 구현

1. `src/lib/db.ts`
   - `subscribeSharedPlaylist(roomId)`를 추가한다.
   - `tracks` 서브컬렉션을 `order asc`로 구독하고 최대 50곡까지 읽는다.

2. `src/store/sharedPlaylist.ts`
   - 공동 큐 서버 상태를 Zustand store로 분리한다.
   - 화면 포커스 중에만 구독하고 에러 시 현재 구독을 정리한다.

3. `app/room/[id]/shared-playlist.tsx`
   - 팀 전체 곡 목록, 유튜브에서 재생, 미리듣기 큐를 제공한다.
   - 삭제/비공개 곡은 핸드오프에서 제외하고, 임베드 불가 곡은 미리듣기에서 제외한다.

4. `app/room/[id]/index.tsx`
   - 홈 상단 영역에 공동 플리 진입점을 추가한다.

# 날짜별 플레이리스트 상세 실데이터 연결 계획

## 배경

홈의 날짜 탭은 `/room/{roomId}/playlist/{dateKey}`로 이동하지만, 상세 화면은 아직 목업 데이터를 표시한다.
사용자는 선택한 날짜에 실제로 모인 곡과 그날의 미션을 확인하고, 유튜브에서 전체 재생할 수 있어야 한다.

## 구현 범위

1. `src/lib/db.ts`에 날짜별 플레이리스트 읽기 함수를 추가한다.
   - 오늘: `tracks(dateKey == today, order by order)`와 `days/{dateKey}`를 `onSnapshot`으로 구독.
   - 과거: 같은 데이터를 `getDocs`/`getDoc`으로 1회 조회.

2. `src/store/playlist.ts`를 추가한다.
   - 상세 화면의 loading/ready/empty/error 상태를 관리한다.
   - 날짜 또는 방이 바뀌면 이전 구독/응답이 새 화면 상태를 덮지 못하게 한다.

3. `app/room/[id]/playlist/[dateKey].tsx`에서 목업 데이터를 제거한다.
   - 라우트 파라미터의 `roomId`, `dateKey`를 기준으로 store를 구독한다.
   - `days.coverVideoId`를 히어로 이미지 우선값으로 사용하고, 없으면 첫 곡으로 폴백한다.
   - 참여자 아바타는 해당 날짜에 곡을 올린 사람 기준으로 표시한다.

## 제외 범위

- 곡 등록/수정/삭제 Functions와 모달은 이 이슈에서 다루지 않는다.
- 날짜 탭 자체를 days 컬렉션 기반으로 바꾸는 작업은 후속 아카이브 작업에서 다룬다.
